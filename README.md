# getweather_bot
Telegram-бот для получения актуальной информации о погоде в Москве через интеграцию с OpenWeatherMap API. Проект обеспечивает удобное взаимодействие с пользователем и предоставляет структурированный вывод метеорологических данных.

Логика работы построена на обработке команд и текстовых сообщений: при запуске бота командой **/start** пользователю отображается reply-клавиатура с кнопкой для запроса погоды. При нажатии кнопки бот формирует GET-запрос к OpenWeatherMap API, получает JSON-ответ и парсит данные для извлечения температуры, ощущаемой температуры, описания погодных условий, влажности и скорости ветра. Полученная информация форматируется в читаемый вид и отправляется пользователю. Проект включает надежную обработку ошибок: неверный API-ключ, отсутствие города, сбои сети. Для обеспечения надежности кода в репозитории предусмотрены юнит-тесты (test_getweather_x1.0.py), проверяющие корректность базовых функций приложения.

Для запуска необходимы Telegram Bot Token и OpenWeatherMap API Key. После установки зависимостей ключи указываются в файле getweather_x1.1.py в переменных **telegram_api** и **openweather_api**.

Python 3.6: **telebot** (pyTelegramBotAPI), **requests**
